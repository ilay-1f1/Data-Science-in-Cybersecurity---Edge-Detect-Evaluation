# Data-Science-in-Cybersecurity---Edge-Detect-Evaluation

This report critically evaluates the paper ”Edge-Detect: Edge-centric Network Intrusion Detection
using Deep Neural Network,” which proposes a lightweight recurrent (LSTM/GRU-based) archi-
tecture for detecting Distributed Denial-of-Service (DDoS) attacks on resource-constrained edge
devices. The project investigates whether the authors’ claims of achieving up to 99% accuracy
with a minimal model footprint are genuinely supported by the data.

Along with the report, provided is a reatempt to reproduce the results disucussed in the paper and comparison of it with a Random Forest model. As the paper emphasizes the model's performance in low-resource, critical environnmnents, some of the comparions are of efficiency in time and in memory usage.
